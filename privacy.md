# Privacy Policy for Tagger's Pet

**Effective Date:** November 24, 2026

## 1. Overview
This Privacy Policy explains how **Tagger's Pet** ("the Bot"), developed and operated by **Tagger** ("we," "us," or "our"), collects, uses, and protects information when you interact with the Bot on Discord. By inviting or using Tagger's Pet in a Discord server, you consent to the practices described in this policy.

## 2. Information We Collect
Tagger's Pet collects only the minimum data necessary to operate its moderation, security, and utility features:
* **Discord Identifiers:** User IDs, Server (Guild) IDs, Channel IDs, and Role IDs required to associate settings, permissions, and records with the correct server and user.
* **Moderation and Security Logs:** Audit records, automated anti-nuke triggers, honeypot interaction events, and moderation actions (such as warnings, timeouts, kicks, or bans) configured by server administrators.
* **Activity and Leaderboard Data:** Message counts, experience points, or server-specific leaderboard metrics generated through user participation in enabled servers.
* **Command Inputs:** Arguments and parameters supplied when invoking slash commands or prefix commands, processed strictly to execute the requested action.

Tagger's Pet does not collect Discord passwords, authentication tokens, payment details, or private direct messages unrelated to direct bot commands.

## 3. How We Use Information
Collected data is used exclusively to:
* Execute user commands and deliver configured server features.
* Enforce automated moderation, anti-nuke protections, and honeypot security defenses.
* Maintain accurate server leaderboards and administrative configurations.
* Prevent spam, rate-limit abuse, and violations of Discord's Terms of Service.

## 4. Data Storage, Retention, and Sharing
* **Storage and Security:** Operational data is stored in access-restricted databases managed by the developer.
* **Retention:** Server configuration and leaderboard records are retained while Tagger's Pet remains active in a server. Temporary security and command logs are cleared periodically.
* **No Third-Party Sales:** We do not sell, rent, or trade user or server data to third parties. Data is never shared externally except when required by law or to report severe abuse to Discord Trust & Safety.

## 5. Your Rights and Data Deletion
* **Server Removal:** Server administrators may stop all data collection at any time by kicking Tagger's Pet from their server.
* **Deletion Requests:** Users or server owners may request the removal of stored records associated with their User ID or Server ID by contacting the developer (**Tagger**) directly via Discord or through the official Tagger's Pet support server.

## 6. Policy Updates
We may update this Privacy Policy as new features are added to Tagger's Pet. Continued use of the Bot after changes are published constitutes acceptance of the revised policy.
